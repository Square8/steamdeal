# GameDil 픽 — Threads 편집 규칙

## 적용
- 게시 예정일의 Asia/Seoul 요일을 기준으로 한다. 요청일과 게시일이 다르면 게시일 우선. 날짜가 불명확하면 한 번 묻는다.
- 수요일: 게임딜 픽 | 지금 살까? 가격·할인·관측 가격 이력 중심.
- 토요일: 게임딜 픽 | 주말에 이거 어때? 취향·플레이 특징·데모 중심.
- 월·화·목·금·일의 기본 추천은 기존 공식 Steam 링크 정책 유지. 기본 추천은 하루 1개.
- 2026-09-30 승인하고 사용자가 4주로 연장한 10/1~10/28 성장 실험에는 화·금 대화·발견 글 1개를 추가한다.
  해당일만 하루 최대 2개이며 수·토는 총 1개 유지. 기존 예약은 변경하지 않는다.
  상세 기준은 `/Users/Work/steam-threads-agent/docs/THREADS_GROWTH_EXPERIMENT.md` 참조.
- 수·토 공개 본문에는 GameDil 상세 링크만 사용. Steam 링크는 내부 검수 근거에만 보관.
- 본문에 반드시 “GameDil AI 추천” 표시. 직접 플레이하지 않았으면 플레이 후기처럼 쓰지 않는다.
- 2026-09-28 사용자 상시 승인에 따라, 매일 운영 보고에서 한국 시간 당일 예약·게시·
  불확실 발행 시도가 모두 없을 때만 GameDil 픽 1개를 검수해 예약할 수 있다. 실험 기간
  화·금에는 확인된 대화 글과 기본 추천 슬롯을 구분하되 실패·불확실 기록이나 로컬과
  매칭되지 않는 실제 글이 있으면 새 예약을 보류한다. 기존 예약은
  수정하지 않는다. 자동 예약에도 후보 파일의 공개 배포와 실제 상세 URL 확인이 필요하다.

## 추천 요청 처리
1. 이 규칙, 게시 이력, 후보 파일을 읽는다. 저장소 전체와 DB는 읽지 않는다.
2. 후보 주소는 https://gamedil.com/assets/editorial-picks.json 이다. 2026-09-28 공개 HTTP 200, schema_version 1, 수·토 후보 각 12개와 GameDil 상세 URL 표본의 HTTP 200을 확인했다. 매번 다시 접근하고 선택한 후보의 데이터를 별도로 재검수한다.
3. 해당 요일 후보에서 최근 28일간 게시/예약한 게임을 제외한다. 사용자 지정 게임은 우선하되 중복 여부를 알려준다.
4. 후보는 데이터 기준의 선별 목록이지 자동 작성된 플레이 평가가 아니다. 게시 전 선택한 1개 게임의 GameDil 상세와 공식 Steam 자료만 재확인한다.
5. 가격·할인·한국어·리뷰는 확인 시점과 근거를 내부 기록에 남긴다. 할인 종료, 오래된 데이터, 자료 충돌 시 다시 검수하거나 다른 후보 제시. 확인 불가면 추측하지 않는다.
6. 추천 이유 1개, 안 맞을 취향/주의점 1개를 근거에 맞춰 작성한다. 플레이 시간·멀티플레이·추억 요소를 이름만 보고 추정하지 않는다.
7. 수요일에는 가격과 관측 이력 중심, 토요일에는 검증 가능한 플레이 특징 중심으로 짧은 초안 1개와 대안 2개까지 제공한다. 후보 부족이면 적게 제시한다.
8. 공개 링크는 해당 appid의 GameDil 상세 주소. utm_source=threads, utm_medium=social, utm_campaign=gamedil_picks, utm_content=YYYYMMDD_wed_APPID 또는 YYYYMMDD_sat_APPID.
9. 게시/예약 완료가 확인되면 이력에 기록한다. 초안만 만든 것을 게시 완료로 기록하지 않는다.

## 다른 채팅방 연결
- 저장소에 접근하는 AI는 이 파일을 먼저 읽는다. 공유 폴더 밖의 채팅은 파일을 자동으로 볼 수 없다.
- 접근 불가하면 이 파일을 첨부하고 기존 고정 지침에 적용한다. 게시 이력 변경도 다시 공유해야 한다.
- 게시 예정일이 수·토면 위 규칙과 후보 자료로 추천한다. 파일 접근/웹 접근 불가면 후보 자료를 요청하며 추천을 지어내지 않는다.
- 수·토에도 2026-09-28 상시 승인에 따른 빈날 자동 예약을 적용한다. 먼저 당일 게시·예약·
  불확실 발행 시도가 없는지 확인하고, 후보·사실 검수에 실패하면 예약 없이 이 작업에 보고한다.
