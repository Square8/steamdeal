# SEO 점검 — 2026-11-11 KST

사용자 제공 5개 경고를 공개 HTTP 응답과 로컬 코드로 확인했다. 점검 시작 작업 트리는 클린이며 제품 코드·호스팅 설정 수정은 하지 않았다.

## 확인한 사실
- HTTP GET 리다이렉트 비활성화 검사에서 http://gamedil.com/ 은 200, Location 없음. http://www.gamedil.com/ 은 301이지만 목적지가 http://gamedil.com/ 이다. 응답 Server는 GitHub.com이고 배포 워크플로도 GitHub Pages다.
- 카테고리 9개 모두 HTTP 200 HTML에서 h1이 0개다. hot-deals, indie-games, korean-demo, korean-games, korean-new, korean-soon, popular-games, recent-drops, under-10000.html.
- build.py build_landing()이 spec['h1']을 h2로 출력한다. 대표 제목을 h1으로 변경하고 theme.py의 .sec-head h2 스타일을 h1에도 적용하면 모양을 유지하며 고칠 수 있다.
- 공개 sitemap.xml 18,253개 URL의 lastmod가 모두 2026-11-11이다. build_sitemap()은 모든 URL에 공통 updated 날짜를 사용한다.
- https://gamedil.com/llms.txt 는 404다.
- 홈·카테고리·유틸리티와 홈 첫 게임 4개 표본에서 제목 60자 초과를 확인하지 못했다. 전체 상세 페이지를 순회하지 않았으므로 경고의 대상 URL은 미확인이다.

## 판단과 수정안
- 우선순위 1. 저장소 Settings → Pages → Enforce HTTPS를 확인하고 활성화 후 HTTP의 HTTPS 이동을 재검증한다. 설정 현재값은 조회하지 않았으며 HTTP 동작만 확인했다.
- 우선순위 2. 카테고리 대표 제목을 h1으로 수정하고 제목 개수·기존 레이아웃·앵커 이동을 검증한다.
- 우선순위 3. lastmod 동일 자체는 오류가 아니다. 주요 내용 변경일을 고려하지 않고 일괄 갱신하는 로직을 개선할 가치가 있다. 신뢰할 수 있는 페이지별 변경일을 만들기 전에는 선택 필드인 lastmod를 생략하는 방법도 가능하다. 가격 확인일 하나를 모든 내용 변경일로 대체하지 않는다.
- llms.txt는 선택 사항이다. Google AI 검색 노출의 필수 조건이 아니며 추가만으로 노출 증가를 보장하지 않는다.
- 제목 60자는 Google의 고정 제한이 아니다. 긴 제목의 실제 대상 확인 후 핵심 게임명·정보를 보존하면서 불필요한 반복을 줄인다. 글자 수만 맞추려고 게임명을 자르지 않는다.
