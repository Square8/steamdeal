# GameDil·Threads 활성화 제안 — 2026-11-11

## 근거와 한계
- 11/9 운영 보고서를 참고했다. 계정·분석 원본을 이번에 다시 조회한 수치는 아니다.
- 보고된 팔로워 173명, Threads UTM 2세션, 사이트 전체 11세션·Steam 이동 4건은 작은 표본이다.
- 4건이 이벤트 수인지 고유 클릭 세션 수인지 확인 전에는 36.4%를 방문자 전환율로 해석하지 않는다. 구매 여부도 알 수 없다.
- 개발자 소개 글에 답글·리포스트가 있었다는 기록은 참여형 소개 실험의 근거다. 성장 원인을 확정하지 않는다.

## 현재 우선순위 — 사용자 의견 반영
- 사용자는 현재 참여를 요청하는 실험보다 팔로워 확보에 집중하기를 원한다. 아래 추천 의뢰·방송·개발자 참여 실험은 후속 후보로 보류한다.
- 다음 2주는 게임 관심 팔로워의 순증과 반복 가능한 콘텐츠 형식 탐색을 우선 제안한다. 자동화 계정 비중과 낮은 참여도는 사용자 관찰이며 이번 점검에서 계정별 검증한 사실은 아니다.
- 기존 게시 슬롯에서 실용 정보, 발견할 만한 인디 게임, 게이머 공감 글의 성과를 비교한다. 사실 확인과 소재 중복 검사를 거치고 참여 응답 없이도 읽을 가치가 있도록 작성한다.
- 프로필과 고정 글에 다루는 게임·정보와 팔로우하면 얻는 것을 명시한다. 게임 이용자·개발자의 실제 대화에 관련 있는 내용으로 참여한다.
- 주간 팔로워 순증, 게시물별 조회·재게시, 확인 가능한 게시물별 신규 팔로우를 기록한다. 게시물별 팔로우가 제공되지 않으면 계정 순증과 게시물 도달을 따로 기록하고 인과를 단정하지 않는다.
- 홈페이지는 기존 소개 링크의 도착지로 활용한다. 운영 변경의 실제 적용은 steam-threads-agent 채팅방에서 담당한다.

## 후속 후보 — 참여가 생기면 재검토
아래는 앞선 참여 실험 후보이며 현재 팔로워 확보 우선순위를 대체하지 않는다.
1. 게임 추천 의뢰 3건을 받아 답한다. 예산·좋아한 게임·피하고 싶은 요소를 받고 각 2개 후보와 근거를 제공한다. 기존 소개 슬롯을 이용하고 GameDil 해당 상세로 연결한다.
2. 일주일 뒤 실제 설치·플레이했는지와 추천이 맞았는지 묻는다. 반복 질문을 기록하고 다음 후보 선택에 반영한다.
3. 주 1회 무료 데모를 30~60분 직접 플레이한다. 방송은 선택 사항이며 실제 관찰 2개·아쉬운 점 1개·맞을 취향을 기록한다. 짧은 클립과 소개 글의 원본으로 사용한다.
4. 개발자 소개는 신청작 1개를 실제 확인하고 질문 하나를 받는 방식으로 시험한다. 신청만으로 추천·상단 배치를 약속하지 않는다.

## 홈페이지 후속 후보
- 기존 상세의 가격·평가·데모 정보에 실제 플레이 메모와 날짜를 소수 게임부터 붙인다. 직접 해본 게임에만 적용한다.
- ‘최근 인하’ 등 기존 정보에서 이전 확인 이후 무엇이 달라졌는지 쉽게 읽게 한다. 단순 순서 교체를 새 정보로 표현하지 않는다.
- 추천 의뢰에서 반복된 조건부터 기존 목록 필터·안내 개선에 반영한다. 인원수·플레이 시간 등 미확보 데이터를 추정하지 않는다.
- Threads의 한 게임 소개는 그 게임 상세, 복수 후보 비교는 해당 목록으로 연결한다. 게시물의 약속과 도착 페이지를 맞춘다.

## 보류한 참여 실험의 실행·판정
- 첫 2주는 기존 게시 슬롯 중 3개를 추천 의뢰·결과 소개로 활용하는 운영 실험을 제안한다. 일일 발행량 증가는 전제하지 않는다.
- 이번 주 사이트 기능 변경이 반영됐다면 운영 실험은 다음 주부터 시작해 기존 동시 변경 금지 원칙을 따른다.
- 같은 분석 도구에서 게시물별 UTM 세션, Steam 클릭이 발생한 고유 세션, 자가 테스트 제외 여부를 맞춘다. 좋아요·팔로워·게임 선택 행동을 각각 기록한다.
- 3건은 수요와 작업 부담을 확인하는 탐색 실험이다. 참여가 없으면 질문 문구·노출을 검토하고, 방문 후 게임 선택이 없으면 추천 적합성을 확인한다. 통계적 승자를 선언하지 않는다.
- Threads 초안·예약·게시 담당은 기존 steam-threads-agent 채팅방이다. 이 문서는 실행 전 제안이다.
