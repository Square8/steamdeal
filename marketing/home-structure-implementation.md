# 2·3단계: 홈 구조·모바일·카드 정리 — 2026-10-29 (Claude)

사용자 지시: "3단계까지 끝내고 커밋·push도 해도 됨, 더 좋은 UI/UX가 있으면 알아서 진행".

## 실제 확인한 문제 (운영 DB 사본 빌드, Playwright 390/1440px)
- 메뉴가 10개였다. 모바일에서는 절반이 화면 밖에 있었고, 핫딜·최근 인하·1만원 이하가 메뉴만 봐서는 어떻게 다른지 알 수 없었다.
- 홈에 섹션 10개가 순서 없이 나열됐다.
- 첫 화면 바로가기 버튼은 홈 맨 아래 전체 목록으로 끌어내렸다. 모바일에서는 버튼 줄도 옆으로 밀어야 보였다.
- 핫딜 전체(hot-deals)는 70% 이상만 보여서 최신 가격 기준으로 0~7개였다. '전체 보기'를 눌러도 거의 비어 있었다.
- 가격이 최신인 카드에도 "가격 확인 날짜" 줄이 붙어 카드가 한 줄씩 길었다.
- 카드에 장르가 없어 무슨 게임인지 알 수 없었다. 칩이 4~5개면 두 줄이 됐다.
- 상세에서 뒤로 돌아오면 필터가 '전체'로 풀리고, 스크롤과 '더 보기'로 펼친 개수가 사라졌다.

## 변경
- 메뉴: 할인·인기·인디·데모·신작·기대작·전체 + 내 찜·비교(구분선). 360px 폭에서도 한 줄에 다 들어간다.
  - 기존 앵커 #hot/#popular/#indie/#new/#all, 페이지 URL, localStorage 키는 그대로다.
- 홈 네 묶음: 할인(눈여겨볼 할인·최근 인하·1만원 이하) → 인기(동접·판매 상위) → 인디·데모 → 신작·기대작 → 전체.
  - 중복 제거도 같은 순서로 적용한다(할인 추천 → 인하 → 1만원 → 인디 → 데모).
- 첫 화면:
  - kicker를 없애고 제목을 줄였다("한국어 스팀 게임, 지금 가격으로 고르기.").
  - 바로가기 7개는 각 목록 페이지로 가는 링크다. 모바일에서는 줄바꿈으로 전부 보인다.
  - '지금 할인' 숫자는 최근에 확인한 가격만 센다.
  - 결과: 390px 첫 화면에 첫 할인 카드가 보인다(할인 섹션 위치 1117px → 452px).
- hot-deals 페이지: 제목을 '지금 할인 중인 게임'으로 바꾸고, 최근 가격을 확인한 할인 중인 한국어 게임 전부로 넓혔다. 홈 추천과의 관계를 안내문에 적었다. slug는 유지했다.
- 카드:
  - 대표 장르 1개를 붙인다(인디·앞서 해보기·무료 플레이 등은 건너뛴다).
  - 칩은 최대 3개다. 경고(한국어 없음·성인)와 평가 칩은 항상 남긴다.
  - 가격 확인 줄은 오래됐거나 확인일이 없을 때만 경고로 보인다.
  - 서버 카드와 JS 카드 4곳(홈·찜·공유·최근 본)에 같은 규칙을 적용했다. 검색 JSON에 `gen`, `pf` 필드를 추가했다.
- 뒤로 가기: 필터를 주소(`?f=`)에 남기고, 스크롤과 펼친 개수는 sessionStorage `gd-home-pos`(탭 한정)에 둔다. back_forward 진입 때만 복원한다.

## 검증
- selftest와 tests 13개 파일 모두 통과.
  - 새 파일 tests/test_home_ux.py(4).
  - 네 묶음·바로가기 selftest를 갱신했고, 메뉴 앵커 15개(3개 화면 폭)가 헤더에 가리지 않는지 PASS.
- 사본 전체 빌드 exit 0. 홈·hot-deals·my-games·korean-demo·popular-games 모두 가로 넘침 0, 칩 3개 초과 0, JS 오류 0.
- 뒤로 가기 실측(390/1440px): 1만원 이하 필터, 48개 펼침, 스크롤 7780/7067px이 그대로 복원됐다.

## 남은 한계·판단
- 할인 단계 기준(DEAL_TIERS) 조정은 보류했다. 새 가격 수집이 아직 운영에서 한 번도 돌지 않았다. #198 수동 실행은 대기열에서 취소됐다(Codex 점검).
- 인기·판매 상위를 탭으로 묶는 Gemini 안은 택하지 않았다. 탭은 한쪽을 가리고 JS가 는다. 두 줄로 나란히 두는 쪽을 골랐다.
- '판매 상위'의 '더 보기'는 여전히 #all로 간다. 전용 목록 페이지가 없다.
- 장르는 Steam 표기를 그대로 쓴다(한국어·영어가 섞일 수 있음).
- push: 이 작업 셸에는 GitHub 인증이 없어 push가 실패했다. 커밋은 로컬에만 있다.
