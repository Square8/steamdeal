# 2026-11-19 GameDil 구매 판단·찜 공유 점검

11/19 02시대 KST 공개 사이트 기준. 11/18 보고서에서 이미 수정한 출시 임박·무료 필터·모바일 배치 항목은 이번 우선순위에서 제외했다. 리뷰 API 없이 기존 데이터로 가능한 변경을 검토했다.

## 수정 우선순위

1. **오래된 가격의 목표가 오판.** FENRIR 공개 상세 JS를 분리 실행해 목표가 10,000원에서 ‘목표가에 도달했습니다’를 재현했다. 카드와 찜 목록의 판정도 가격 신선도 조건이 없다. 가격은 ‘마지막 확인가’로 보존하고 도달 배지·정렬·현재 할인 추천은 보류한다. 마지막 가격이 목표 이하였다는 사실과 재확인 필요 여부를 같은 문장에 쓰면 작은 경고를 읽기 어려운 사용자도 판단할 수 있다.
2. **찜의 공유 범위.** 내 찜에서 성인 게임 보기를 끄면 표시 목록에서만 제외한다. 공유 버튼은 저장된 ID 전체의 앞 30개로 링크를 생성한다. 공개 JS를 임시 ID 두 개와 해제된 체크박스로 실행해 두 ID 모두 링크에 포함됨을 확인했다. 실제 이용자 데이터나 클립보드는 사용하지 않았다. 필터·정렬 적용 후 화면에 보이는 순서에서 최대 30개를 사용하고, ‘현재 보이는 N개 공유’로 범위를 명시한다.
3. **대형 목록과 작은 찜 목록의 초기 비용.** 공개 한국어 목록은 카드 6,109개, HTML 6.23 MB(압축 0.67 MB), 데모는 2,845개, HTML 3.03 MB(압축 0.30 MB)다. 찜이 1개여도 캐시가 없으면 21,516건 검색 파일을 받는다. JSON 11.42 MB, gzip 1.75 MB. 큰 목록은 48개씩 고유 URL을 둔 페이지로 나누고 전체 정렬을 유지한다. 찜·공유·최근 본 게임은 ID별 묶음으로 필요한 데이터만 받는 방식을 검토한다. 실제 저사양 휴대폰 지연 시간은 미측정이다.

## 하나만 추가한다면

기존 할인 전체에 **‘1만원 이하 + 관측 최저가’** 바로가기를 둔다. 11/18 공개 색인에 한국어·비성인·출시 상태·최근 가격 확인·할인 중·유료 1만원 이하·기존 최저가 배지를 모두 충족하는 항목이 62개였다. 기존 30~59일과 60일 이상 배지 표기를 보존하고 URL로 같은 조건을 다시 열 수 있게 한다. CTA 클릭과 그 결과에서의 상세 진입을 재면 홈에 고정할지 판단할 수 있다.

검증 범위는 공개 화면·공개 JS·공개 가격 응답이다. 화면 낭독기, 실사용 전환율, Google 색인 효과는 측정하지 않았다. 이번 작업은 점검 및 제안이며 서비스 소스 변경·배포는 없다.

## 후속 구현과 로컬 검증

- 오래된 가격은 마지막 확인가로 표시한다. 할인 추천 가점·선정 이유와 최저가 강조에서 제외하고, 상세·찜·카드의 목표가 도달 판정에는 실제 UTC 관측일을 사용한다. 목표가와 마지막 확인가는 보존한다.
- 내 찜에서 성인 표시 여부와 정렬을 적용한 뒤 앞 30개까지만 공유한다. 받은 목록은 공유한 순서로 열리며 숫자 ID만 담은 기존 링크도 계속 사용할 수 있다.
- 찜·공유·최근 본 목록은 필요한 ID가 든 묶음만 읽는다. 실제 사본 21,516개를 128개 묶음에서 중복·누락 없이 복원했다. FENRIR 한 개 조회 예시는 전체 색인 11.85 MB에서 94.53 KB로 줄었다(압축 전).
- 한국어 게임 6,109개는 128페이지, 데모 2,845개는 60페이지로 나눴다. 기존 첫 페이지 URL을 보존하고 후속 페이지마다 고유 URL을 생성한다. 양쪽 목록 모두 전후 ID 집합이 일치했다. 한국어 목록의 첫 HTML은 6.26 MB에서 90 KB, 데모는 3.04 MB에서 93 KB로 줄었다. 전체 목록 정렬용 데이터는 정렬을 선택할 때 받는다.
- 홈 할인 아래 ‘1만원 이하 + 관측 최저가’ 바로가기를 추가했다. 할인 전체의 독립 필터와 URL을 공유하며, 같은 DB 사본의 조건 충족 62개와 브라우저에 표시된 ID가 일치했다. 무료 배포 상점 확인 시각은 당일에도 월/일을 표시한다.
- 로컬 Chromium으로 360·390·1280·1440px에서 홈·무료 배포·한국어 목록·데모 목록·조합 할인·FENRIR 상세를 확인했다. 가로 넘침·JS 오류·로드된 이미지 깨짐 0건. [홈·무료 1280/390 전후 화면](site-live-audit-2026-11-19/04-local-before-after.jpg)
- selftest.py 644개 검사와 tests/test_*.py 15개 파일 통과. 사본으로 build.py를 끝까지 실행해 상세 21,516개를 생성하고 사이트맵 URL 19,802개의 고유성과 대상 파일 존재를 검증했다. 운영 DB·site/ 변경, 커밋·push·배포 없음.
