## 절대 유지
- 브라우저 자동화(남의 글 좋아요·댓글·팔로우)는 재가동하지 않는다.
- API 쓰기는 내 피드 발행(본문 + 첫 댓글)과 내 글에 달린 답글 응답만 한다.
- 새 기능·새 페이지·새 제보 시스템은 만들지 않는다. 사람 손이 필요한 절차(동의 확인, A/B 장면, 의견 정리)는 하지 않는다.
- 지킬 수 없는 약속 문구 금지: "내일 골라줄게", "후기 연결", "소개해줄게" 등.

## 1. 링크 규칙
- 모든 슬롯 본문에 URL 금지. 링크는 발행 직후 첫 댓글(reply_text)에 단다. 근거·출처·구매 링크를 한 댓글에 모은다.
- 본문만 읽어도 판단에 필요한 정보가 완결돼야 한다. "링크 달라고 댓글 달아" 같은 유도 금지.
- 발행 전 검사: 본문에 http(s)://, www., 도메인 패턴이 있으면 예약·발행 차단.
- 첫 댓글 실패: 이미 달린 댓글이 없음을 API로 확인할 수 있을 때만 1회 재시도. 확인 불가면 재전송하지 않고 기록.
- GameDil 링크 UTM 유지.

## 2. 슬롯 개편 (시각은 그대로, 할당량이 아니라 발행 기회)
- 08 뉴스: 알려진 게임의 확인된 변화 1개 + 플레이어에게 미치는 영향 + 이미지. 의견 질문으로 끝. IR·매출·단순 출시 보도 제외. 쓸 소식 없으면 비운다.
- 12 팁/주말 무료: 실제 문제와 해결. 최근 30일 중복 제외. 무료배포는 영구소장/체험 구분과 KST 마감 명시. 새 정보 없으면 비운다.
- 16 인디: 주 3회 이하. 제보작 또는 검증된 후보. 대표 장면 + 실제 특징 1개. 플레이 평가 금지. 후보 없으면 비운다.
- 19 할인: 무명 1작 → 기준 하나(예산/취향)로 최대 3개. 게임별 현재가·관측 최저가·한국어·평가·확인 시각. 할인 0%·가격 확인 2일 초과 제외. 3개 못 채우면 1개도 허용하되 기준은 명시.
- 23 대화: 무명작 지식 없이 답할 수 있는 번호 선택형(1/2/3). 같은 밤 할인작 재홍보 금지.
- 하루 최소 08·19·23 세 개는 발행을 시도한다. 12·16은 조건 충족 시만.
- 모든 글에 관련 주제 태그 1개(무관한 인기 태그 금지).

## 3. 글쓰기
- 말투는 친구 반말 하나로 통일한다(존댓말 금지). threads-writing-guide.md의 금지 상투구를 적용한다.
- 첫 줄에 무엇에 관한 글인지 드러낸다. 질문은 하나, 한 단어로 답할 수 있게.
- 예시 (사실·수치는 게시 전 확인):
  - 08: "[게임] 이번 패치에서 [확인된 변화] 바뀌었대. 이거 때문에 접었던 사람 돌아올 만해? (출처는 댓글에)"
  - 19: "한국어 되고 1만 원 이하인데 평가 '압도적 긍정'인 거, 지금 할인 중인 것만 추렸어 / 1. ○○ 4,950원 / 2. ○○ 6,600원 / 3. ○○ 8,900원 / 이 중에 안 해본 거 있어?"
  - 23: "평생 하나만 해야 한다면? / 1. 스타듀밸리 / 2. 테라리아 / 3. 림월드"

## 4. 프로필
- 소개란 제안 문구(사용자 확인 후 적용): "한국어 되는 스팀 할인, 가격 이력까지 확인해서 매일 정리 / 인디게임 제보 받아요". 플레이 후기 약속은 넣지 않는다.
- 고정글은 기존 인디 개발자 제보 방명록 글을 유지한다.

## 5. 측정 (2주)
- 글별 24시간·72시간 시점의 조회, 다른 사람의 고유 참여자 수, 다른 사람의 답글 수, 리포스트·인용, UTM 방문. 계정 일별 팔로워 순증.
- 운영자 첫 댓글과 자동 답글은 집계에서 뺀다. 측정이 안 되는 값은 만들어내지 않는다.
- 같은 형식이 3회 연속 다른 사람 반응 0이면 소재·질문을 바꾼다.
- 기준선: 아웃리치 중단 후(11/13~) 글을 같은 24/72h 시점으로 재집계한다. 이번 시험은 묶음 개편이라 링크 위치 단독 효과로 해석하지 않는다.
- 매주 월요일에 표로 보고한다.

## 6. 작업 순서와 보고
1) 링크 규칙과 발행 전 검사 + 테스트 → 2) 이미 예약된 글 수정 → 3) 슬롯별 생성 규칙 변경 → 4) 측정 집계.
- 단계마다 바뀐 파일, 테스트 결과, 수정된 예약 글의 전후 본문을 보고한다.
- 첫날 실제 발행된 글 전문을 사용자에게 보여 준다.
