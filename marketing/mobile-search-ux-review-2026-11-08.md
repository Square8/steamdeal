## 자동완성 최적화 실측

- 홈 상단 첫 입력에서 기존에는 자동완성과 전체 목록이 같은 인덱스를 각각 요청했다. 이제 자동완성은 비성인 게임 17,193개의 가벼운 파일만 읽고, 전체 목록은 검색 실행 또는 해당 영역 진입 시 읽는다. 제안의 썸네일 자리는 게임명 첫 두 글자를 사용한다.
- 동일 운영 데이터로 로컬에서 같은 설정으로 gzip 압축한 결과는 1,441,174B → 247,217B로 82.8% 감소다. 압축 전은 9,901,670B → 736,038B다.
- 390×844 Chromium 모바일 모드에서 캐시 없이 4Mbps·지연 150ms를 적용했다. `No Man` 입력부터 제안 DOM 표시까지 각 5회 측정한 중앙값은 6,073ms → 683ms다. 외부 요청은 차단했으며 실기기 또는 운영 서버 실측은 아니다.
- `No Man`, `방 탈출`, `Counter-Strike`, `PEAK`의 결과 순서, 링크, 가격, 할인 표기가 전후 같았다. 검색 실행 시 전체 파일 요청과 UTM 보존, 지연 응답 시 닫기 동작 및 404 검색 경로를 검증했다. 운영 주소 의존 404 렌더 3건은 환경 제약으로 스킵했다.
