# 배포 실패(사이트 1GB 한도) 수정 — 2026-11-24 (Claude)

## 증상
- Actions #269(예약): 수집과 가격 이력 커밋은 됐지만 배포 단계에서 `No artifacts named "github-pages"` 오류가 났다.
- 공개 사이트는 11/22 19:31 UTC 배포(데이터 11-23 03:56 KST)에서 멈춰 있다. 이후 실행들도 배포에 실패했을 가능성이 높다. 각 실행 로그는 gh CLI가 없어 직접 보지 못했다.

## 원인
- 운영 DB 사본으로 전체 빌드하면 site가 972.7MB(파일 22,218개)다. GitHub Pages 게시 한도는 1GB다.
- 상세 페이지 1개가 약 52KB인데, 그중 29KB가 스크립트다. 찜·비교·검색·헤더·공유·갤러리 등 모든 상세에 같은 내용이 인라인으로 반복된다.
- 게임 수가 계속 늘어서 한도를 넘었다. 업로드 경고 1건과 배포 오류 3건이 이 상황과 맞는다.

## 수정
- build.py에 `SharedScripts`를 추가했다.
  - 상세 페이지에서 50페이지 이상 반복되고 400자 이상인 인라인 `<script>`를 `assets/js/<해시>.js`로 빼고, 같은 자리에서 `<script src>`로 불러온다.
  - 동기 실행이라 순서와 동작은 같다. 브라우저 캐시 덕분에 상세 페이지를 연달아 볼 때 더 빨라진다.
  - 페이지별 데이터가 든 가격 차트 스크립트(`var pts`)와 type이 있는 스크립트(JSON-LD 등)는 그대로 둔다.
- 테스트: tests/test_shared_scripts.py(2). selftest와 tests 전체 통과.
