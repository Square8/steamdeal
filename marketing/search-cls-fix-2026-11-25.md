# 상세 페이지 검색 대응 + 홈 화면 밀림 수정 — 2026-11-25 (Claude)

근거: marketing/analytics-review-2026-11-25.md. 네이버 검색이 유입의 59%이고, 주요 착지는 신작·출시예정 상세였다. 홈 CLS는 0.332였다.

## 1. 홈 화면 밀림(CLS) 수정
- 재현: 새 브라우저(캐시 없음) 1440px에서 0.7초쯤 CLS 0.35가 발생했다.
  - 처음에는 웹폰트(Gothic A1)가 적용되기 전이라 헤더 메뉴(nav.jump)가 로고·검색과 같은 첫 줄에 들어간다.
  - 웹폰트가 적용되면 글자가 넓어져 메뉴가 둘째 줄로 떨어지고, 헤더가 48px 커지면서 화면 전체가 밀렸다.
- 수정: theme.py `nav.jump{flex-basis:100%}`. 메뉴는 처음부터 항상 둘째 줄에 둔다. 최종 모양은 이전과 같다.
- 결과(사본 사이트, 캐시 없는 새 브라우저):
  - 홈 PC 0.35 → 0.002, 모바일 0.002.
  - 상세 PC 0.001, 모바일 0.006~0.03.
  - hot-deals 모바일 0.029.

## 2. 상세 페이지 검색 대응
- 제목:
  - 출시예정은 "출시일 X"(날짜가 없으면 "출시 예정")를 넣는다.
  - 공통으로 "한국어 지원"과 "데모"를 덧붙인다.
  - 예: "Hospital Hustle — 출시 예정 · 한국어 지원", "MAR: Millions Are Rising — 출시일 2026년 · 한국어 지원". 출시작은 가격·할인을 유지한다.
- 설명(meta description):
  - 기존 "스팀 원화 가격과 변동 이력." 상투구 대신 게임 소개(최대 90자)를 앞에 둔다.
  - 뒤에 사실 요약(관측 최저가·긍정률·한국어·데모·출시일·대표 장르)을 붙인다.
  - "출시 예정 출시"처럼 말이 겹치던 문제도 고쳤다.
- 모바일 첫 화면: 제목 왼쪽에 작은 표지(104px, 560px 이하에서만)를 둔다. 구매 정보가 위로 올라오면서 첫 화면에 게임 그림이 없던 문제를 보완한다. width·height를 지정해 밀림은 없다.
