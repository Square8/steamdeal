# GameDil 구매 판단 흐름 점검 — 2026-11-08 KST

- 범위는 라이브 사이트의 390×844 화면에서 상세, 비교함, 할인 전체를 직접 이용한 결과다. 검색 용량, 홈 헤더, 목록 복귀는 [앞선 점검](mobile-search-ux-review-2026-11-08.md)에 있다.

1. **상세의 숫자 일치부터 수정.** No Man’s Sky는 평가 요약과 정보 표에 423,502개, ‘이 게임을 고른 이유’에 317,830개가 나온다. Overcooked! 2도 85,084개와 62,719개가 동시에 나온다. 이유를 만드는 `store.py`는 `review_count`, 상세 요약은 `review_total` 우선이다. 표시용 평가 수를 한 기준으로 맞추고 이유에서 같은 숫자를 반복하지 않는 안을 권한다.
2. **상세 첫 화면의 구매 판단 정보를 위로.** No Man’s Sky는 모바일에서 트레일러가 이름보다 먼저 나오고 현재가는 화면 약 y=605부터 보인다. Overcooked! 2는 상단에 현재가와 최저가 대비 차액을 제공하지만, 비교 기준인 41일과 최저가 6,500원은 아래쪽에 있다. 이름·가격·가격 확인 시점·관측 기간을 상단에서 묶고 트레일러와 설명을 이어서 배치하면 된다. 카드·상세에서 같은 의미로 ‘관측 최저가’를 쓴다.
3. **할인 목록의 평가순과 필터를 보완.** 325개 목록에서 ‘평가 좋은 순’ 상위 다섯 게임은 100%에 리뷰 18·9·6·3·1개였다. 99%·1,507개의 Woodo는 여섯 번째였다. ‘긍정률순’은 명시하고, 평가를 고르는 기본 경로에는 최소 리뷰 수나 표본을 반영한 정렬을 검토한다. 이 목록에는 정렬은 있으나 예산·데모·리뷰 수 조합 필터는 없었다. 소수의 빠른 필터와 적용 후 결과 수가 유용하다.
4. **모바일 비교는 두 게임을 한 화면에.** 두 게임을 담아 비교했을 때 390px에서 행 제목과 첫 게임은 보이지만 두 번째 게임이 잘려 좌우 스크롤이 필요했다. 세 번째 미사용 열도 ‘비어 있음’으로 반복된다. 실제 선택 개수만 렌더링하고, 모바일에서 현재 저장가·관측 최저가·평가·한국어부터 두 게임을 나란히 보여준다. 저장 당시 가격/확인일 표기는 유지한다.
5. **가격 그래프의 변동 횟수 표기 통일.** 두 상세에서 본문은 가격이 ‘2번 바뀌었습니다’로, 스크린리더용 그래프 설명은 ‘변동 3회’로 나온다. 관측 시작 가격 1건과 이후 변동 횟수를 구분해서 계산과 문구를 통일한다.

- 제안 순서. 평가·변동 숫자 일치 → 기존 상세 요약을 첫 화면으로 이동 → 할인 목록 빠른 필터와 평가 정렬 → 모바일 비교.
- 테스트용 비교 항목 두 개를 제거했다. 라이브 게임 가격의 Steam 상점 일치 여부, 실제 터치 기기 및 스크린리더 동작은 별도 검증 범위다.

## 로컬 구현과 검증

- 상세는 모바일에서 이름·가격·관측 기간·최저가 차이·평가·구매 버튼을 트레일러 위에 표시한다. 추천 이유의 중복 리뷰 수를 제거했다. 가격 차이는 확인된 최신 가격에만 표시하며, 그래프 본문과 접근성 설명은 같은 방식으로 가격 변동을 센다.
- 할인 전체에 1만원 이하, 데모 있음, 리뷰 100개 이상을 조합할 수 있게 했다. 표시 수를 갱신하고 URL에 조건을 저장한다. 기존 긍정률 정렬을 ‘긍정률순’으로 표기한다.
- 비교함은 담긴 게임만 표시하고 가격·최저가·평가·한국어를 위쪽에 배치한다. 390px에서 두 게임은 가로 스크롤 없이, 세 게임은 기존과 같이 가로로 넘겨 비교한다.
- 390px 브라우저에서 상세 가격 상단 배치, 본문·그래프 설명 2회 일치, 필터 세 개와 낮은 가격순 적용 및 새로고침 복원, UTM 보존, 비교 두 게임의 표 잘림 없음과 세 게임·무료 가격을 확인했다. 기본 검사 580개, 탐색·정렬 103개, 표시 정확성 4개 통과.
- 동일 운영 DB 사본으로 변경 전후 전체 빌드 성공. 상세 18,794개 포함 HTML 18,811개로 파일 추가·누락 0건. 공통 CSS 버전·비교 저장 호환 코드와 후보 JSON 생성 시각을 제외한 변경 범위는 상세, 목록 9개, 비교, CSS다. 검색 인덱스·추천 후보·사이트맵은 같은 결과를 확인했다.
