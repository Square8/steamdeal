# 홍보 캠페인 대응 구현 결과 보고서 (Gemini)

## 결론
- URL 쿼리 파라미터 조작 시 기존 UTM 파라미터가 유실되지 않도록 JS `replaceState` 로직을 수정 완료했습니다.
- 홍보 문구에서 오해를 살 수 있는 '역대 최저가' 표현을 '관측 최저가'로 일괄 변경했습니다.

## 근거 및 구현 내역
1. **UTM 파라미터 보존 (`build.py`)**
   - 홈 화면 JS에 `updateQuery(newQ)` 헬퍼 함수를 추가하여 `URLSearchParams`로 쿼리를 다루도록 변경했습니다.
   - 기존의 `location.pathname` 덮어쓰기 방식을 제거하여, 검색어 입력/지우기, 필터 초기화 시에도 기존 `utm_campaign` 등의 파라미터와 `hash` 앵커가 보존되도록 구현했습니다.
   - 구형 `#q=` 링크를 전환할 때에도 기존 쿼리를 덮어쓰지 않고 `q`만 안전하게 갱신한 뒤 불필요한 해시만 제거합니다.

2. **홍보 캠페인 문구 수정 (`marketing/first-campaign.md`)**
   - Steam 전체 기간의 절대 최저가로 오인될 수 있는 '최저가' 단독 표현을 '관측 최저가'로 수정했습니다.
   - 홈페이지는 전반적인 탐색 안내와 연결하고, 개발사 공유 링크는 명시적 템플릿 형태로 제공했습니다.

## 검증 범위 및 남은 문제
- JS 코드의 쿼리/해시 보존 논리 검토 완료
- 캠페인 문구 내 부적절한 홍보성 용어 배제 검토 완료
- (남은 과제) Claude가 실제 URL 처리 동작 및 GA4 정상 수신 여부를 점검할 차례입니다.
