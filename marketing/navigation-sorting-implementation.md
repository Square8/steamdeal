# 구현 완료: 홈 탐색 통일 및 카테고리 정렬 (Codex 2차 리뷰 반영)

Codex 리뷰 및 재검수에서 지적된 문제들을 모두 수정하고 `selftest.py` 검증을 통과했습니다.

## 1. 구현 내용

- **홈 메뉴 일관성**
  - 상단 메뉴 버튼("지금 인기", "최근 인하")과 모든 랜딩 페이지의 "홈으로 돌아가기" 링크가 홈의 앵커 해시로 동작하도록 업데이트했습니다.
  - `#under-10000` (1만원 이하) 섹션을 신설하고 빈 상태 시 안내 문구를 적용했습니다.
- **제목 가림 해결 및 앵커 클릭 개선**
  - `ResizeObserver`로 헤더 높이를 감지해 CSS 변수 `--header-height`를 적용하고 `scroll-padding-top`을 주었습니다.
  - 앵커 해시 클릭 시 `history.replaceState`와 `scrollIntoView`로 스무스 스크롤을 연동하되, 보조 키(Ctrl/Cmd 등) 클릭과 외부 링크는 방해하지 않도록 처리했습니다.
  - OS `prefers-reduced-motion` 환경을 감지하여 애니메이션을 자동으로 차단합니다.
- **모든 카테고리/랜딩 정렬 (DOM Sorting)**
  - `build.py`의 `card(g)` 렌더러에 HTML `data-*` 속성(`data-rev`, `data-pos`, `data-price`, `data-free` 등)을 추가 배정해 정렬 상태를 관리합니다.
  - 원본 카드의 시각적 렌더링(할인 리본, 동접 뱃지 등)을 훼손 없이 유지하며, DOM Node 순서만 재배열하여 성능과 안전성 제약을 통과했습니다.
- **정렬 상태 복원 및 URL 동기화**
  - 사용자가 브라우저 뒤로/앞으로 가기(`popstate`) 시 URL의 `sort` 쿼리 파라미터를 읽어 UI 선택(`select#lsort`)과 카드 정렬을 자동으로 동기화합니다.
  - 무쿼리 첫 진입 시 지연 로딩을 유지하고, 쿼리가 있다가 사라질 땐 기존 로딩된 데이터를 기준으로 `apply`를 실행해 정렬과 필터를 초기 상태로 복구합니다.
- **korean-soon 오류 수정 및 미정/무료 가격 정렬 보완**
  - `korean-soon` 랜딩의 `pick` 및 `sort` 조건을 원본 로직으로 되돌려 날짜(`release_date`) 문자열 음수화 연산에 의한 TypeError를 해결했습니다.
  - 높은 가격순(내림차순) 정렬 시 '가격 미정'인 게임(`null`/`Infinity`)이 가장 위로 올라오는 버그를 방지하기 위해 뺄셈 전 양쪽의 `null` 여부를 먼저 판단하여 미정 게임을 항상 뒤로 보내도록 로직을 수정했습니다.

## 2. 테스트 및 검증 결과

`selftest.py` 검증 통과를 완료했습니다:
- 최근 갱신 내역 부재 시 "최근 가격이 내려간 게임이 없습니다." 문구 확인 (섹션 자체는 유지)
- `nav` 태그 `aria-label` 갱신 (`"주요 탐색"`)
- URL 인자 조작(`?q=` 제거 로직) 통과
- 후행 공백(trailing spaces) 8곳 정리

추가적인 DB 수정이나 기존 제품 코드 기능의 무단 훼손 없이, 지적된 Codex 코드 리뷰의 회귀 이슈까지 정확하게 반영해 수정 완료했습니다.
