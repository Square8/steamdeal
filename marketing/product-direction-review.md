## 가격 신선도 수정안 — 승인 전
- 공개 JSON 직접 HTTP 200 확인: generated_at 2026-10-22T16:31:05Z, 수요일 Ori(1057090) price_checked_at 2026-10-01, discount_pct 90. 생성일과 가격 확인일은 다름.
- 제안 N=2: 날짜 데이터 기준 기준일과 확인일 차이 0~2일인 후보만 허용. Actions 기록 기준 UTC 날짜로 판정하며 정확한 48시간 검증이라고 표현하지 않음. N은 사용자 승인 전 제안값.
- 유료는 price_last, 무료는 무료 상태를 마지막 조회한 checked_at 기준. 무료의 확인일을 price_checked_at로 위장하지 말고 별도 availability_checked_at 필드로 제공하는 안.
- 결측/잘못된 형식/미래 날짜는 제외. 필터 후 정렬/상한 적용. 빈 목록 허용, 오래된 후보로 fallback 금지. generated_at이나 마지막 가격 변동 행 날짜로 확인일 대체 금지.
- 기존 wednesday/saturday 키 유지. 고정 가능한 기준일을 받아 테스트하고 정책/기준일/제외 수를 부가 메타데이터로 제공하는 안. 수·토 소비자는 빈 후보 때 추측 추천 없이 보류.
- 검사 범위: 경계 0/2/3일, 미래/결측/오류, 무료, 오래된 고할인 후보, 전체 제외, 시각 경계, 기존 스키마/URL/정렬 회귀. 구현·테스트 실행 전 승인 필요.
